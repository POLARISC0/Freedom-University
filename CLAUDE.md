# Polaris Vending website

A one-page website for business owners who might host a Polaris Vending machine. Polaris Vending is part of the Polaris family.

Read the DNA at the start of every session, in this order:

1. `dna/PROJECT_DNA.md`: what this is, the Polaris story, the brand rules and the look
2. `dna/ARCHITECTURE.md`: every file and how they connect
3. `dna/SETUP.md`: how to preview and edit it on a Windows PC
4. `dna/STATUS.md`: what's done, what's missing, and what's next

## How we work

- **Minimal code.** Make the smallest change that fully does the job. It's plain HTML, CSS and a few lines of JavaScript, so keep it that way. No frameworks, no build step, and no packages for a few lines.
- **Plain language.** Use short sentences and no jargon, on the page and in chat.
- **Preview after each change.** Run `npm run preview` and show me the page (a screenshot at phone and desktop size) before moving on. Then wait for my feedback.
- **Ask one question instead of guessing.** If something isn't clear, ask me one question rather than assuming.
- **Follow the brand rules in `dna/PROJECT_DNA.md`.** Above all, never promise anyone income.
- **Leave the PLACEHOLDER markers** until I give you the real details.
- **Run `npm test` after changes.** It checks the sections, the exact wording and the contact form.
